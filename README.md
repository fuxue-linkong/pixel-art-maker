# pixel-art-maker

图片转像素画工具:上传图片 → 拖动/缩放选取 → 多算法生成像素艺术 → 下载。

## 功能

- 图片上传(点击/拖拽)
- 拖动移动、滚轮缩放,方形取景框选取
- 分辨率调节(默认 24×24,4–128)
- 多种转换算法:
  - 平均色 (Average)
  - 最近邻 (Nearest)
  - 量化 (16 色调色板)
  - Floyd-Steinberg 抖动
- 锐化调节(0–100%)
- 网格显示开关
- 输出放大倍数可选(8× / 12× / 16× / 24× / 32×)
- 一键下载 PNG

## 部署

通过 GitHub Actions 自动部署到 GitHub Pages,推送 `main` 分支即触发。
